# MySQL — Curso em Vídeo

Repositório criado para registrar meus estudos e exercícios realizados durante o curso de **MySQL** do **Curso em Vídeo**, ministrado por **Gustavo Guanabara**.

## 📚 Conteúdo

O repositório acompanha a sequência das aulas do curso, com um arquivo `.sql` correspondente a cada aula:

* `aula3.sql`
* `aula4.sql`
* `aula5.sql`
* ...
* `aula16.sql`

## 🗂️ Tópicos estudados

Durante o curso, foram abordados conceitos como:

* Criação e gerenciamento de bancos de dados
* Criação e alteração de tabelas
* Inserção, atualização e exclusão de dados
* Consultas com `SELECT`
* Filtros e ordenação
* Operadores `LIKE`, `BETWEEN`, `IN`, `AND` e `OR`
* Funções de agregação
* `GROUP BY` e `HAVING`
* Relacionamentos entre tabelas
* Chaves primárias e estrangeiras
* `INNER JOIN` e `LEFT JOIN`
* Relacionamentos `1:1`, `1:N` e `N:N`
* Tabelas associativas

## 🎯 Objetivo

Consolidar os fundamentos de **SQL e MySQL** por meio de prática, acompanhando minha evolução ao longo do curso.
